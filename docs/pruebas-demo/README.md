# Documentación de pruebas para la demo de Kontrol

## Objetivo

Registrar las pruebas utilizadas para preparar y demostrar el funcionamiento
de Kontrol, indicando la versión evaluada, los escenarios ejecutados,
sus resultados y la evidencia correspondiente.

Esta documentación corresponde a una actividad independiente de UX-N
y de las pruebas realizadas en el Neurolab.

## Preparación

- Entorno utilizado: enlace en producción.
- Datos de prueba utilizados: carga de datos de prueba para que navegaran los participantes.
- Roles utilizados: participante/usuario común.
- Condiciones o limitaciones de la demostración: No se logró probar múltiples roles con el fin de obtener comentarios de la mayor parte de arreglos implementados en los últimos 2 sprints (9 y 10).
