# Media para la presentacion de Kontrol

Coloca aqui los archivos audiovisuales que quieras mostrar dentro de la
presentacion. No necesitas editar el HTML si respetas estos nombres.

## Videos

- `videos/09-demo-recorrido.mp4`
  - Video corto opcional para la slide de cierre de demo.
  - Recomendacion: recorrido de 45 a 90 segundos.

## Recomendaciones

- Usa resolucion horizontal, idealmente 1600x900 o similar.
- Si no agregas un archivo, la presentacion mostrara un placeholder con el
  nombre esperado.
- Si quieres cambiar nombres o agregar mas medios, edita `index.html` en los
  bloques que tengan `data-src`.
